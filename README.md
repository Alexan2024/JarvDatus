# Личный ассистент в Telegram

Бот, который каждое утро присылает сводку, спрашивает план на день,
а вечером разбирает, что сделано. Умеет отвечать на вопросы и искать
в интернете.

---

## Что он умеет

**Утром (по умолчанию 8:00)**
1. Присылает бриф: погода, календарь, почта, новости, незакрытые задачи.
2. Спрашивает план на день. Вы отвечаете как удобно, обычным текстом:
   «доделать отчёт до созвона, позвонить маме, вечером зал».
3. Собирает список дел, объединяя ваш ответ, события календаря и хвосты
   с прошлых дней. Новые задачи улетают в TickTick.

**Вечером (по умолчанию 21:00)**
1. Показывает утренний список и спрашивает, что закрыто.
2. Отвечаете свободно: «отчёт сделал, зал слился, лендинг наполовину».
3. Закрывает выполненное в TickTick, показывает итог дня и серию,
   спрашивает про незакрытое — перенести или снять.

**В любой момент**
- Просто пишете вопрос — отвечает Claude, ответ печатается «вживую».
- «Найди новости про X» — ищет в интернете и отвечает со ссылками.
- За 15 минут до встречи из календаря присылает напоминание.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | список команд |
| `/status` | сводка систем: почта, задачи, ближайшая встреча, расход API |
| `/tasks` | что бот видит в TickTick (для проверки подключения) |
| `/brief` | прислать бриф прямо сейчас |
| `/plan` | показать план дня; `/plan new` — составить заново |
| `/debrief` | запустить вечерний разбор досрочно |
| `/setup` | ссылки для подключения Gmail и TickTick |
| `/diagnostics` | проверка всех подключений |
| `/tone` | переключить тон: дворецкий ↔ деловой |
| `/remember текст` | запомнить факт о вас навсегда |
| `/forget` | стереть запомненные факты |
| `/reset` | очистить историю диалога |

## Установка

Полная пошаговая инструкция — в файле **SETUP.md**. Открывайте его и идите
по пунктам сверху вниз, ничего не пропуская.

## Из чего состоит

```
app/
  main.py             точка входа
  config.py           чтение настроек
  db.py               база (SQLite на диске Railway)
  render.py           ASCII-оформление сообщений
  claude_client.py    общение с Claude + поиск в интернете
  brief.py            сборка утреннего брифа
  planning.py         утренний план и вечерний разбор
  bot.py              команды Telegram
  scheduler.py        расписание 8:00 / 21:00 / пинги
  web.py              страница подключения Gmail и TickTick
  integrations/
    gmail.py          почта
    calendar.py       Apple Calendar через CalDAV
    tasks.py          общий доступ к задачам
    ticktick_mcp.py   TickTick по токену (основной способ)
    ticktick.py       TickTick по OAuth (запасной способ)
    mcp_client.py     клиент протокола MCP
    weather.py        погода (Open-Meteo, без ключей)
    news.py           новости из RSS
```

## Сколько стоит

- Railway — от 5 $/мес.
- Claude API — примерно 3–15 $/мес при повседневном использовании.
  Текущий расход видно в `/status`.
- Поиск в интернете — 10 $ за 1000 запросов, то есть копейки.
- Погода и новости — бесплатно.

## Известные ограничения

- **Apple Reminders не поддерживаются** — у них нет публичного API.
  Задачи живут в TickTick.
- **Apple Calendar только на чтение**, обновляется опросом раз в 5 минут:
  у iCloud нет мгновенных уведомлений для сторонних программ.
- Для TickTick лучше завести отдельный список (по умолчанию `Jarvis`):
  так задачи бота не смешиваются с остальными, а при доступе по старому
  OAuth системный Inbox через API вообще не виден.
- При смене основного пароля Apple ID все пароли приложений слетают,
  и календарь придётся подключить заново.
