# Установка — пошагово

Кодить не нужно. Нужно завести несколько аккаунтов и скопировать ключи.
Идите строго сверху вниз. Всего около 30 минут.

Заведите заранее пустой текстовый файл — будете складывать туда ключи.

---

## Шаг 1. Токен Telegram-бота

1. Откройте Telegram, найдите **@BotFather**.
2. Отправьте `/newbot`.
3. Придумайте имя (любое) и username (должен заканчиваться на `bot`).
4. BotFather пришлёт строку вида `1234567890:AAH...` — это **TELEGRAM_TOKEN**.
   Скопируйте в свой файл.

## Шаг 2. Ваш ID в Telegram

1. Найдите бота **@userinfobot**, отправьте ему любое сообщение.
2. Он пришлёт число вида `123456789` — это **OWNER_ID**.
   Благодаря ему бот будет отвечать только вам.

## Шаг 3. Ключ Claude

1. Зайдите на **console.anthropic.com**, зарегистрируйтесь.
2. Пополните баланс (раздел Billing, хватит 5–10 $ для начала).
3. Раздел **API Keys** → Create Key → скопируйте строку `sk-ant-...`
   Это **ANTHROPIC_API_KEY**. Показывается один раз — сохраните сразу.

## Шаг 4. Придумайте пароль установки

Придумайте любую длинную строку без пробелов, например
`kluch-ot-moego-bota-7391`. Это **SETUP_KEY** — им защищены ссылки
подключения почты и задач.

## Шаг 5. Загрузка на GitHub

1. Распакуйте архив — получится папка с файлами.
2. Зайдите на **github.com**, зарегистрируйтесь.
3. Нажмите **+** справа сверху → **New repository**.
4. Имя любое, например `jarvis`. Обязательно выберите **Private**.
   Нажмите Create repository.
5. На открывшейся странице нажмите ссылку **uploading an existing file**.
6. Перетащите в окно браузера **содержимое** распакованной папки —
   то есть файлы `README.md`, `requirements.txt`, `Procfile` и папку `app`.
   Важно: перетаскивать нужно сами файлы, а не папку целиком.
7. Внизу нажмите **Commit changes**.

## Шаг 6. Деплой на Railway

1. Зайдите на **railway.com**, войдите через GitHub.
2. **New Project** → **Deploy from GitHub repo** → выберите репозиторий.
3. Railway начнёт сборку. Первый запуск упадёт — это нормально,
   переменные ещё не заданы.

### Диск для базы

4. Откройте сервис → вкладка **Settings** → раздел **Volumes** →
   **Add Volume**. Mount path укажите: `/data`

### Переменные

5. Вкладка **Variables** → **New Variable**. Добавьте по одной:

```
TELEGRAM_TOKEN     = из шага 1
OWNER_ID           = из шага 2
ANTHROPIC_API_KEY  = из шага 3
SETUP_KEY          = из шага 4
DB_PATH            = /data/jarvis.db
TZ_NAME            = Europe/Moscow
MORNING_TIME       = 08:00
EVENING_TIME       = 21:00
WEATHER_LAT        = 55.7558
WEATHER_LON        = 37.6173
RSS_FEEDS          = https://lenta.ru/rss/news,https://www.vedomosti.ru/rss/news
```

Координаты своего города можно найти, вбив в поиск
«широта долгота <город>». Ленты новостей меняйте на любые свои,
через запятую без пробелов.

### Адрес сервиса

6. **Settings** → **Networking** → **Generate Domain**. Порт укажите `8080`.
   Railway выдаст адрес вида `jarvis-production.up.railway.app`.
7. Вернитесь в **Variables** и добавьте:

```
PUBLIC_URL = https://jarvis-production.up.railway.app
```

(подставьте свой адрес, обязательно с `https://` и без косой черты в конце)

8. Сервис перезапустится сам. Через минуту бот в Telegram напишет
   «Ассистент на связи, сэр». Отправьте ему `/start`.

**На этом основное готово.** Бот уже отвечает на вопросы, ищет в интернете,
присылает погоду и новости. Дальше — подключение почты, задач и календаря,
каждое по желанию и независимо от остальных.

## Шаг 7. Почта Gmail (по желанию)

1. Откройте **console.cloud.google.com**, войдите под своим гуглом.
2. Сверху создайте новый проект (New Project), имя любое.
3. Слева **APIs & Services** → **Library** → найдите **Gmail API** → **Enable**.
4. **APIs & Services** → **OAuth consent screen**:
   - тип **External**, далее заполните только обязательные поля
     (название приложения, ваша почта);
   - на шаге **Test users** нажмите Add и впишите свой gmail-адрес;
   - сохраните.
5. **APIs & Services** → **Credentials** → **Create Credentials** →
   **OAuth client ID**:
   - Application type: **Web application**;
   - в разделе **Authorized redirect URIs** нажмите Add URI и вставьте:
     `https://ваш-адрес.up.railway.app/auth/google/callback`
     (тот же адрес, что в PUBLIC_URL, с этим хвостом);
   - Create.
6. Скопируйте **Client ID** и **Client secret**.
7. В Railway → Variables добавьте:

```
GOOGLE_CLIENT_ID     = ...
GOOGLE_CLIENT_SECRET = ...
```

8. Дождитесь перезапуска, напишите боту `/setup` — он пришлёт ссылку.
   Откройте её, разрешите доступ. Появится надпись «Готово».

Если Google покажет предупреждение «приложение не проверено» — нажмите
«Дополнительно» → «Перейти на сайт». Это ваше собственное приложение.

## Шаг 8. Задачи TickTick (по желанию)

Есть два способа. Первый проще — используйте его.

### Способ 1: токен (рекомендуется)

1. В приложении TickTick создайте список с названием **Jarvis** —
   туда бот будет складывать задачи.
2. Откройте TickTick в браузере (ticktick.com), войдите.
3. Нажмите на свой аватар слева сверху → **Settings** (Настройки) →
   **Account** (Аккаунт) → **API Token**.
4. Создайте ключ, дайте ему любое имя и скопируйте строку целиком.
   Она начинается на `tp_`. Показывается один раз — сохраните сразу.
5. В Railway → Variables добавьте:

```
TICKTICK_TOKEN        = tp_...ваш токен целиком...
TICKTICK_PROJECT_NAME = Jarvis
```

6. Дождитесь перезапуска и напишите боту `/tasks` — он покажет,
   что видит в вашем аккаунте. Ссылку из `/setup` открывать не нужно.

Этот токен даёт полный доступ к задачам — храните его как пароль
и никому не показывайте.

### Способ 2: приложение OAuth (если первый не подошёл)

1. Откройте **developer.ticktick.com**, войдите своим аккаунтом.
2. **Manage Apps** → кнопка **+App Name** → имя любое.
3. Откройте созданное приложение, в поле **OAuth Redirect URL** впишите:
   `https://ваш-адрес.up.railway.app/auth/ticktick/callback`
4. Скопируйте **Client ID** и **Client Secret**.
5. В Railway → Variables добавьте:

```
TICKTICK_CLIENT_ID     = ...
TICKTICK_CLIENT_SECRET = ...
TICKTICK_PROJECT_NAME  = Jarvis
```

6. После перезапуска напишите боту `/setup` и откройте ссылку TickTick.

Если заданы обе пары переменных, бот выберет токен из способа 1.

## Шаг 9. Календарь Apple (по желанию)

1. Откройте **appleid.apple.com**, войдите.
2. Раздел **Вход и безопасность** → **Пароли для приложений** →
   создайте новый, название любое.
3. Скопируйте выданный пароль из 16 символов (вида `abcd-efgh-ijkl-mnop`).
4. В Railway → Variables добавьте:

```
APPLE_ID           = ваша почта от Apple ID
APPLE_APP_PASSWORD = abcd-efgh-ijkl-mnop
```

Двухфакторная аутентификация должна быть включена, иначе Apple не даст
создать такой пароль.

## Проверка

Отправьте боту `/diagnostics` — он покажет, что подключилось, а что нет:

```
┌──────────────────────────┐
│ ДИАГНОСТИКА              │
├──────────────────────────┤
│ ✓ почта                ок │
│ ✓ задачи               ок │
│ ✓ календарь            ок │
│ ✓ Claude               ок │
│ ✓ диск                 ок │
└──────────────────────────┘
```

Затем `/brief` — придёт сводка прямо сейчас, не дожидаясь утра.

## Если что-то не работает

**Бот молчит.** Railway → вкладка **Deployments** → откройте последний,
посмотрите **Logs**. Строка «Не заданы переменные» подскажет, чего не хватает.

**Бот отвечает «Этот бот приватный».** Неверный OWNER_ID — перепроверьте
число из шага 2.

**Ссылка `/setup` выдаёт «Доступ закрыт».** Не задан SETUP_KEY либо
он отличается от того, что в ссылке. Проверьте переменную.

**Google пишет `redirect_uri_mismatch`.** Адрес в Google Cloud должен
совпадать с PUBLIC_URL символ в символ, включая `https://` и хвост
`/auth/google/callback`.

**Календарь показывает «ошибка».** Обычно это обычный пароль Apple ID
вместо пароля приложения. Нужен именно 16-символьный из шага 9.

**Задачи не появляются в TickTick.** Напишите боту `/tasks` — команда
покажет режим подключения, список найденных возможностей и текущие задачи.
Убедитесь, что список `Jarvis` существует и назван точно так же, как
в переменной `TICKTICK_PROJECT_NAME`. Если в ответе `/tasks` пусто,
пришлите его текст — по названиям возможностей будет видно, что поправить.

**Хочу изменить время сводок.** Railway → Variables → поменяйте
`MORNING_TIME` и `EVENING_TIME`, сервис перезапустится сам.
